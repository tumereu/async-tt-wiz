# Bundled mockup fonts

These unmodified font files were downloaded through Google Fonts on 2026-10-21
to make the static mockup sources render without remote requests. Filenames are
the first 20 hexadecimal characters of their SHA-256 digest. CSS in each source
maps the files to family/weight/unicode ranges.

- **Inter:** Copyright 2020 The Inter Project Authors
  (<https://github.com/rsms/inter>), SIL Open Font License 1.1. See `Inter-OFL.txt`.
- **Roboto:** Copyright 2011 The Roboto Project Authors
  (<https://github.com/googlefonts/roboto-classic>), SIL Open Font License 1.1.
  See `Roboto-OFL.txt`.
- **Material Symbols Outlined:** Google Material Design icons, Apache License
  2.0. See `Material-Symbols-LICENSE.txt`; upstream:
  <https://github.com/google/material-design-icons>.

The Stitch exports also use browser/system font fallbacks. Tailwind utility CSS,
where present in a generated export, is retained as static compiled styles;
Tailwind CSS is MIT licensed. See `Tailwind-LICENSE.txt`.

These are documentation/mockup dependencies, not selections or release clearance
for the application. No card artwork is bundled in this pilot.
